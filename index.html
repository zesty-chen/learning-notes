博客设置与发布

连接博客仓库后，发布的内容可在手机和其他电脑上查看。访客可以阅读，只有持有仓库写入权限的人可以发布。

如何取得发布权限？

在 GitHub 的 Settings → Developer settings → Personal access tokens → Fine-grained tokens 中创建令牌；仅选择此博客仓库，授予 Contents 的 Read and write 权限，并设置有效期。将令牌填到上方输入框。不要将令牌写入任何笔记或源代码。

这是公开博客：发布的文字和链接会写入 GitHub 仓库；删除后的历史版本仍可能存在于 Git 历史中。

备份与恢复

导出包括公开内容和本机草稿，不包含访问令牌。
